Monthly restock report

Purchase = max(0, safety stock − physical inventory M). Physical inventory comes from this month's box counts, grouped by model. M-1 is the previous month's snapshot. Distributed comes from the delivery tool's JSON export.

Stock flow check estimated

Each request moves exactly one PC, so the workforce implies an expected stock change: returns (leavers) add, hand-outs (joiners) remove. Compared against the real physical change, the gap is what reconciliation must explain.
